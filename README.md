# 📚 Historique Claude — Plugin d'Archivage Automatique

Ce plugin permet d'archiver automatiquement vos conversations Claude (VS Code et Cowork) dans plusieurs formats pour une gestion et une analyse simplifiées.

## ✨ Fonctionnalités

*   Archive les conversations VS Code et Cowork.
*   Support multi-format (TXT, JSON, CSV, Markdown).
*   Filtrage par date et par mot-clé (keyword).
*   Intégration et support de Google Drive.
*   Automatisation nocturne des archivages.

## 📖 Installation

Pour installer le plugin, téléchargez le fichier `.plugin` directement depuis la dernière [Release](https://github.com/ryle58-sudo/historique-conversations/releases).
